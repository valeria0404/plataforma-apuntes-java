# Especificación de Requisitos de Software

## Requisitos Funcionales

- **RF-01:** Registro de usuarios (estudiantes).
- **RF-02:** Publicación de apuntes por asignatura con URL de contenido.
- **RF-03:** Búsqueda y filtrado de apuntes por asignatura.
- **RF-04:** Sistema de valoraciones (estrellas / me gusta).

## Requisitos No Funcionales

- **RNF-01:** Arquitectura orientada a objetos (POO).
- **RNF-02:** Control de versiones en GitHub.
